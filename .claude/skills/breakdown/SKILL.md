# Разбор эпизода → промты для Omni Flash

## 0. Подготовка
- Перечитай `CLAUDE.md`, `knowledge/omni-flash-prompting.md`, `knowledge/lessons.md`,
  `show/show-bible.md` и карточки в `show/characters/`, `show/locations/`.
- Если библия шоу пустая или нет карточки персонажа — сначала коротко спроси
  недостающее (формат кадра, закадр или речь в кадре, внешность героя).
  Не выдумывай внешность главного героя без согласования.

## 1. Сохранить исходники
- Номер и slug эпизода: `episodes/NN-slug/` (скопируй `episodes/_TEMPLATE/`).
- Сценарий → `script.md` как есть; субтитры → `subtitles.srt` (или `.vtt`).

## 2. Сетка слотов
```
python3 tools/srt_slots.py episodes/NN-slug/subtitles.srt -o episodes/NN-slug/slots.md
```
- Слоты можно объединять/двигать по смыслу (не по механике), но:
  каждая сцена ≤ 6 с, граница — между фразами, а не посреди слова.
- Короткие соседние реплики с одним смыслом — одна сцена.
- Слоты-перебивки (паузы) — атмосферные/переходные кадры.
- Без субтитров: оцени тайминг по сценарию (~2.5 слова/с русской речи) и
  пометь, что тайминг приблизительный.

## 3. Шот-лист (`shotlist.md`)
Для каждой сцены: что видим и **зачем** (как кадр поддерживает текст озвучки),
крупность и движение камеры, режим Flow, референсы, подрезка.
Режиссёрские принципы:
- Чередуй крупности (общий → средний → деталь), не ставь подряд два одинаковых.
- Иллюстрируй смысл, а не буквально слова; ищи визуальную метафору/шутку.
- Действие одно и простое — в 6 с много не уместится.
- Продумай стыки: направление движения, свет и цвет между соседними сценами.
- Открывающий кадр — крючок; финальный — точка.

## 4. Промты (`prompts.md`)
- Формат карточки — `templates/shot-prompt.md`.
- Якоря стиля, персонажа и локации — **дословно** из `show/`.
- Каркас: камера → стиль → свет → локация → персонаж → действие → звук → текст.
- По умолчанию `single continuous shot, no cuts`.
- Звук: если озвучка внешняя — `No dialogue, no voiceover, no music.` + SFX/эмбиент.
- Прогони каждый промт по чек-листу из `knowledge/omni-flash-prompting.md`.

## 5. Выдача пользователю
- Короткая таблица сцен (№, таймкод, суть, режим Flow).
- Затем все карточки; промт каждой — в отдельном код-блоке для копирования.
- В конце: что проверить первым тестом и какие референсы сгенерировать заранее.
- Закоммить файлы эпизода.
