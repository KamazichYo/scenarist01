# Один промт для Omni Flash

1. Прочитай `knowledge/omni-flash-prompting.md`, `knowledge/lessons.md` и нужные
   карточки в `show/`.
2. Определи задачу:
   - **Новая сцена** → карточка по `templates/shot-prompt.md`.
   - **Референс персонажа/локации** → промт из `templates/character.md` /
     `templates/location.md` (нейтральный фон, ровный свет, фронтально).
   - **Правка готового клипа** → режим редактирования Flow: нумерованный список
     изменений + `Keep everything else identical — same character, same framing,
     same timing, same audio.` Одна-две правки за раз.
   - **Фидбек «не сработало»** → разбери причину по разделу «Известные слабости»,
     предложи исправленный промт и **запиши урок** в `knowledge/lessons.md`.
3. Типовые исправления:
   - Появилась склейка → `single continuous shot, no cuts, one unbroken take`,
     убрать слова «then cut», упростить действие.
   - Поплыл персонаж → прикрепить референсы (Ingredients), вставить якорь
     дословно, использовать Frames с первым кадром.
   - Лишняя музыка/голос → `No music. No dialogue. No voiceover.`
   - Появился текст → `no subtitles, no on-screen text, no captions`.
   - Лишний объект/человек → позитивная формулировка пустоты
     («an empty corridor with no people»).
   - Кривые руки/сложная моторика → упростить действие, сменить крупность,
     убрать руки из кадра.
4. Выдай промт в код-блоке, по-английски, и одной строкой по-русски — что изменилось.
