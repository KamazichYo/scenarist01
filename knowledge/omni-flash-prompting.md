# Gemini Omni Flash — как писать промты (выжимка)

Собрано из официальных гайдов Google DeepMind / Google Cloud и практических разборов
(список в `sources.md`). Модель вышла на Google I/O (май 2026), доступна в Gemini App
и Google Flow. Omni — «any-to-any»: на вход текст, картинки, видео, аудио; на выходе
видео со звуком. Звук генерируется вместе с картинкой, отдельного аудио-прохода нет.

## Базовые параметры

- Длительность: 3–10 с, **дефолт 6 с** (во Flow используем 6).
- Форматы: 16:9 и 9:16 (уточнять под шоу).
- Продление клипа (extend) шагами до ~40 с суммарно.
- Режимы во Flow: текст→видео; первый/последний кадр (Frames); референсы
  персонажей/объектов/локаций (Ingredients); редактирование видео разговором;
  продление.

## Структура промта

Официальные 5 элементов (DeepMind):
1. **Shot framing & motion** — крупность + движение камеры. **Идёт первым.**
2. **Style** — визуальный язык (cinematic, 35mm film, claymation, anime, documentary…).
3. **Lighting** — источник + качество (warm practical lamp, hard noon sun, neon…).
4. **Location** — место, эпоха, погода — обобщённо, без перечисления мелочей.
5. **Action** — кто, что делает, как взаимодействует. Глаголы, последовательно.

Плюс для нас обязательно:
6. **Audio** — диалог / SFX / эмбиент / «no music».
7. **Text** — либо точный текст и место, либо «no on-screen text».

Правило: описывай **решения режиссёра**, а не физику (не надо объяснять, как
отражается мокрый асфальт — модель это знает). 3–6 предложений лучше абзаца
прилагательных. Omni требует меньше прескриптивности, чем Veo — опиши цель,
он дорисует детали.

## Камера

- Модель читает кино-термины как инструкции: `static / locked-off`, `slow push in`,
  `pull out`, `dolly zoom`, `orbit`, `tilt up`, `pan left`, `handheld`,
  `tracking shot`, `crane up`, `POV`, `over-the-shoulder`, `natural smartphone zoom`,
  `webcam style`, `film camera`.
- Если камеру не указать — по умолчанию средний план, статика.
- Последовательность движений можно задать по времени словами:
  «close-up that tilts up to a medium shot, then widens», «push in starts at 3 seconds
  and reaches a close-up by 6 seconds».

## Склейки vs один дубль

- **Omni по умолчанию режет между ракурсами.** Нужен один дубль — пиши
  `single continuous shot, no cuts` / `one unbroken take`.
- Не смешивай две грамматики: либо биты со склейками («begin on the wheels, cut to
  the driver»), либо одно движение («one continuous aerial tracking the car»).
- Мульти-шот внутри клипа — таймкоды (синтаксис Veo, Omni понимает):

```
[00:00-00:03] Close-up of ... SFX: ...
[00:03-00:06] Wide shot, ... 
```

## Звук

- **Реплика:** `The man says in a calm low voice: "Текст реплики."` — кавычки
  обязательны, иначе текст может уйти в титры или не прозвучать. Указывать
  голос/акцент/интонацию.
- **SFX:** перечислять каждый звук отдельно (`SFX: keys jingle, door creaks open`).
- **Эмбиент:** слоями (`Ambience: distant traffic, light rain on the window`).
- Явно запрещать лишнее: `No music. No dialogue. No voiceover.` — иначе модель
  может добавить музыку или закадровый голос.
- Лип-синк стабилен примерно до 6–7 с и **одного говорящего в кадре**; при двух
  говорящих реплики путаются → одна реплика одного персонажа на клип.
- Русская речь официально не задокументирована — **проверить тестовым клипом**,
  записать результат в `lessons.md`.

## Консистентность персонажа

- **Ingredients / референсы:** прикладывать референс-картинки персонажа
  (фронтальный, нейтральный свет). Генерировать их заранее (Nano Banana / Imagen)
  и хранить в `show/characters/<имя>/`.
- В промте ссылаться явно: `Using the provided reference image for <Имя>...`.
- **Дословный якорь внешности** в каждом промте (одно-два предложения, не меняются
  ни на слово): возраст, телосложение, причёска, одежда, 1–2 приметы.
- **Первый кадр (Frames)** фиксирует композицию и палитру — меньше дрейфа.
- Ожидать небольшой дрейф на длинных сериях — проверять и при необходимости
  править через редактирование («change only X, keep everything else identical»).

## Редактирование в Flow

- Одна правка за раз, точечно. Заканчивать фразой
  `Keep everything else identical.`
- Несколько правок — нумерованным списком, а не прозой.
- Можно менять фон, ракурс, движение, текст, объект, стиль без пересборки сцены.

## Текст в кадре

- Точные слова в кавычках + место + длительность: `Display the word "СТОП" in large
  white letters centered on screen for two seconds.`
- Текст — слабое место (опечатки, повторы, особенно кириллица) → по возможности
  делать титры на монтаже, в промте — `no on-screen text`.

## Известные слабости

- Сложная/быстрая моторика, драки, руки, мелкие предметы в руках.
- Текст (особенно не латиница).
- Консистентность при многократных правках.
- Негативные ограничения иногда игнорируются («no hands» — а рука появилась).
- Ориентация объектов может зеркалиться; люди «проходят» сквозь преграды.
- 3D-эффекты без конкретного термина выходят плоскими.

## Шпаргалка: каркас промта

```
[CAMERA: shot size + movement], single continuous shot, no cuts. [STYLE]. [LIGHTING].
[LOCATION ANCHOR]. [CHARACTER ANCHOR] [ACTION — 1 ясное действие, глаголами].
Audio: [SFX / ambience / dialogue "..." / no music, no dialogue, no voiceover].
No subtitles, no on-screen text, no logos.
```

## Чек-лист перед выдачей промта

- [ ] Первая фраза — крупность + движение камеры
- [ ] Указано: один дубль или биты с таймкодами (не смешаны)
- [ ] Якорь персонажа и локации вставлен дословно из `show/`
- [ ] Одно главное действие, укладывается в 6 с
- [ ] Звук прописан; если озвучка внешняя — `no dialogue, no voiceover, no music`
- [ ] Реплика в кадре (если есть) ≤ ~5 с, в кавычках, один говорящий
- [ ] Про текст в кадре сказано явно
- [ ] Исключения сформулированы позитивно
- [ ] Указаны режим Flow и нужные референсы
- [ ] Указан тайминг подрезки, если сцена короче 6 с
- [ ] Перечитан `lessons.md`
