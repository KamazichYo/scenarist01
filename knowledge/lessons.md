# Уроки с практики

Пополняется по фидбеку пользователя. Формат:

```
## YYYY-MM-DD — эпизод / сцена
- Было: ...
- Результат: ...
- Исправили: ...
- Правило: ...
```

## Открытые вопросы для проверки
- Как Omni Flash произносит русские реплики (качество, акцент, лип-синк)?
- Держится ли персонаж по Ingredients-референсу от сцены к сцене?
- Слушается ли `single continuous shot, no cuts` на 6 с стабильно?
